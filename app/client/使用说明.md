# Go SDK 使用说明

`client` 是 WellRead 后端的 Go HTTP 客户端，封装认证、空间、知识库、文档、会话、流式问答、模型和分块等接口，避免调用方重复拼 HTTP 请求。

该 SDK 与后端 `app/` 同仓维护；接口字段以 [Swagger](../docs/swagger.yaml) 为准，示例代码见 [example.go](example.go)。

## 1. 模块边界

- 面向服务端/工具/脚本集成，不包含前端逻辑。
- 认证支持 Bearer Token、租户 API Key、空间上下文。
- 资源权限仍由后端守卫决定；SDK 不做额外授权。
- 部分历史接口（Agent/MCP/技能/记忆/沙箱）仍保留在包内，但产品面是否开放以后端路由与当前部署为准。

## 2. 创建客户端

```go
import (
    "context"
    "gaze/client"
    "time"
)

apiClient := client.NewClient(
    "http://localhost:8080",
    client.WithToken("your-jwt-or-api-token"),
    client.WithTimeout(30*time.Second),
)
```

常用选项：

| 选项 | 作用 |
|---|---|
| `WithToken` | Bearer token / API token |
| `WithAPIKey` | 租户 API Key |
| `WithBearerToken` | Bearer JWT |
| `WithTenantID` | 默认空间，自动带 `X-Tenant-ID` |
| `WithTimeout` | HTTP 超时 |
| `WithTransport` | 自定义 `http.RoundTripper` |

临时切换空间：

```go
ctx := context.WithValue(context.Background(), "TenantID", uint64(10000))
```

`uint64`、`*uint64` 和数字字符串都可识别；context 值优先于客户端默认值。

## 3. 知识库与文档

```go
kb, err := apiClient.CreateKnowledgeBase(ctx, &client.KnowledgeBase{
    Name:             "合规知识库",
    Description:      "内部制度与监管文件",
    EmbeddingModelID: "embedding-model-id",
})
if err != nil { return err }

knowledge, err := apiClient.CreateKnowledgeFromFile(
    ctx, kb.ID, "policy.pdf", map[string]string{"source": "local"},
)
```

常用方法：

- `CreateKnowledgeBase` / `GetKnowledgeBase` / `ListKnowledgeBases` / `UpdateKnowledgeBase` / `DeleteKnowledgeBase`
- `CreateKnowledgeFromFile` / `CreateKnowledgeFromURL` / `CreateManualKnowledge`
- `ListKnowledge` / `GetKnowledge` / `DeleteKnowledge` / `ReparseKnowledge` / `CancelKnowledgeParse`
- `HybridSearch` / `SearchKnowledge` / `ListKnowledgeChunks`

上传后解析是异步的；轮询 `GetKnowledge` 的 `ParseStatus`，或使用 `GetKnowledgeProcessingSpans` 查看阶段。

## 4. 会话与流式问答

```go
session, err := apiClient.CreateSession(ctx, &client.CreateSessionRequest{
    KnowledgeBaseID: kb.ID,
    SessionStrategy: &client.SessionStrategy{
        MaxRounds:        5,
        EnableRewrite:    true,
        FallbackStrategy: "fixed_answer",
        FallbackResponse: "抱歉，我无法回答这个问题",
    },
})

err = apiClient.KnowledgeQAStream(ctx, session.ID, &client.KnowledgeQARequest{
    Query:            "跨境支付有哪些合规要求？",
    KnowledgeBaseIDs: []string{kb.ID},
}, func(resp *client.StreamResponse) error {
    fmt.Print(resp.Content)
    return nil
})
```

- 流式回调可能收到答案增量、引用、错误和结束事件；按 `StreamResponse` 字段处理。
- Agent 问答使用 `NewAgentSession` / `AgentQAStream`；流中断可用 `ContinueStream` 等流恢复方法。

## 5. 检索与分块

```go
results, err := apiClient.HybridSearch(ctx, kb.ID, &client.SearchParams{
    QueryText: "跨境支付",
    MatchCount: 10,
})

chunks, total, err := apiClient.ListKnowledgeChunks(ctx, knowledgeID, 1, 20)
```

`HybridSearch` 是同步检索，不生成答案；适合 RAG 调试和工具调用。分块编辑、删除、生成问题等接口需要后端写权限。

## 6. 模型与空间

```go
models, err := apiClient.ListModels(ctx)
tenant, err := apiClient.GetTenant(ctx, tenantID)
resp, err := apiClient.SwitchTenant(ctx, client.SwitchTenantRequest{TenantID: tenantID})
```

- 模型管理需要 `manage_models` 或 full-access API Key。
- `SwitchTenant` 会重新签发 token，并更新最近活跃空间偏好。
- 空间/成员/邀请接口受公司角色限制。

## 7. 错误处理

SDK 返回 Go `error`；HTTP 非 2xx 通常包含状态码、响应体和后端错误码。建议：

```go
if err != nil {
    var httpErr *client.HTTPError
    if errors.As(err, &httpErr) {
        // 按 httpErr.StatusCode / httpErr.Body 处理
    }
}
```

具体错误类型以包内定义为准；不要只匹配错误字符串。

## 8. 集成建议

- 服务端调用使用短期 token/API Key，不把密钥写进代码。
- 大批量上传要限制并发，并轮询解析状态，避免压垮 docreader。
- 流式问答设置合理 context timeout；中断时取消 context。
- 只使用当前部署实际开放的接口；以 Swagger 和路由为准。
- 完整示例见 [example.go](example.go)，字段定义见 [Swagger](../docs/swagger.yaml)。
