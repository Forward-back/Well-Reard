# DocReader 服务说明

DocReader 是 WellRead 的文档解析 gRPC 服务。Go app 把上传文件交给它解析，拿到 Markdown/纯文本、表格、图片引用和元数据，再写入知识库与 RAG。DocReader 不管理用户、权限、知识库或对象存储。

## 1. 职责边界

| 负责 | 不负责 |
|---|---|
| PDF/DOCX/PPTX/XLSX/Markdown/HTML/EPUB/图片等解析 | 认证、RBAC、KB/ACL |
| 表格提取、扫描页渲染、图片抽取 | 对象存储持久化（由 Go app 负责） |
| 文档元数据补全、格式归一化 | RAG 分块/embedding/检索 |
| gRPC 健康检查、TLS/token 鉴权 | 前端展示 |

扫描 PDF 由 DocReader 渲染为 JPEG，OCR/VLM 由 Go app 侧调用；DocReader 自身不内置 OCR/VLM 后端。

## 2. 运行方式

### app 栈内（推荐）

```bash
cd WellRead
docker compose -f deployments/docker-compose.yml up -d docreader
```

服务只在 compose 网络内暴露 `50051`，app 通过 `DOCREADER_ADDR=docreader:50051` 访问。

### 本地开发

```bash
cd app
uv sync --project docreader
uv run --project docreader python -m docreader.main
```

依赖 Python 3.10+（项目镜像使用 3.11）。默认监听 `50051`，健康检查用 `grpc_health_probe -addr=localhost:50051`。

## 3. 主要模块

| 路径 | 作用 |
|---|---|
| `main.py` | gRPC server、健康检查、TLS/token 拦截器 |
| `config.py` | 环境变量与解析参数 |
| `auth.py` | TLS/mTLS 与 `GRPC_AUTH_TOKEN` |
| `parser/registry.py` | 解析器注册与格式路由 |
| `parser/chain_parser.py` | 多解析器链式回退 |
| `parser/pdf_parser.py` | PDF 文本/扫描页/图片处理 |
| `parser/docx_parser.py`、`xlsx_parser.py`、`pptx_parser.py` | Office 解析 |
| `parser/web_parser.py`、`mhtml_parser.py`、`html_parser.py` | 网页/MHTML |
| `parser/markdown_parser.py`、`epub_parser.py`、`image_parser.py` | 其他格式 |
| `parser/ums_metadata.py` | 业务元数据补全 |
| `client/` | Go 客户端（供 app 调用） |

## 4. 支持格式

- 文档：PDF、DOCX、DOC、PPTX、XLSX/XLS、Markdown、TXT、EPUB、RTF/ODT（经 MarkItDown 等回退）
- 网页：HTML、MHTML、URL 抓取
- 图片：PNG/JPEG 等，交给上游多模态链路
- 结构化：Excel 表格转 Markdown/结构化行

具体可用解析器由 `parser/registry.py` 注册表决定；新增格式需同时补 registry、parser 和测试。

## 5. 配置

### gRPC

| 变量 | 默认 | 说明 |
|---|---|---|
| `DOCREADER_GRPC_PORT` / `PORT` | 50051 | 监听端口 |
| `DOCREADER_GRPC_MAX_WORKERS` | 4 | gRPC 工作线程 |
| `DOCREADER_GRPC_MAX_FILE_SIZE_MB` / `MAX_FILE_SIZE_MB` | 50 | 文件大小上限 |
| `DOCREADER_IMAGE_OUTPUT_DIR` | `/tmp/docreader` | 临时图片目录 |

### 解析资源

| 变量 | 默认 | 说明 |
|---|---|---|
| `DOCREADER_DOCX_MAX_PAGES` | 0（不限） | DOCX 最大页数 |
| `DOCREADER_MARKITDOWN_MAX_WORKERS` | 1 | MarkItDown 并发 |
| `DOCREADER_PDF_RENDER_MAX_WORKERS` | 1 | 扫描 PDF 渲染并发（0=关闭限流） |
| `DOCREADER_PDF_RENDER_PARALLELISM` | min(4, CPU) | 单 PDF 内页级并行 |
| `DOCREADER_PDF_RENDER_DPI` | 200 | 渲染 DPI |
| `DOCREADER_PDF_JPEG_QUALITY` | 85 | JPEG 质量 |
| `DOCREADER_PDF_RENDER_MAX_EDGE` | 2000 | 长边像素上限，防超大图 |

### 可选 ODl/MarkItDown

| 变量 | 说明 |
|---|---|
| `DOCREADER_ODL_HYBRID` | `off` / `auto` / `on` |
| `DOCREADER_ODL_HYBRID_URL` | OpenDataLoader 服务地址 |
| `DOCREADER_ODL_HYBRID_MODE`、`..._FALLBACK` | 混合模式与回退 |
| `DOCREADER_ODL_MARKDOWN_WITH_HTML` | Markdown 保留 HTML |
| `DOCREADER_EXTERNAL_HTTP_PROXY` / `..._HTTPS_PROXY` | 外部抓取代理 |

### TLS / 鉴权

| 变量 | 说明 |
|---|---|
| `GRPC_TLS_ENABLED` | `true` 时必须提供证书/私钥，否则 fail-fast |
| `GRPC_TLS_CERT` / `GRPC_TLS_KEY` | 服务端证书/私钥 |
| `GRPC_TLS_CA` | CA；存在时默认启用客户端证书校验 |
| `GRPC_MTLS_REQUIRE_CLIENT_CERT` | 强制 mTLS |
| `GRPC_AUTH_TOKEN` | 设置后启用 token 鉴权 |

存储后端（local/MinIO/COS/OSS）由 Go app 侧配置；DocReader 只把图片以 inline bytes 返回，由 app 持久化。

## 6. 测试与质量

```bash
cd app
uv sync --project docreader
uv run --project docreader python -m compileall -q docreader
uv run --project docreader python -m unittest discover -s docreader/tests -p "test_*.py" -v
```

CI 还会跑 Go client 测试：`go test ./docreader/client ./docreader/proto`。

测试重点：

- 各格式解析不崩溃、Markdown/表格结构稳定。
- 扫描 PDF 渲染与图片抽取。
- 元数据补全。
- gRPC 健康检查与 TLS/token 鉴权。
- 超时/取消和并发限流。

## 7. 常见问题

| 现象 | 排查 |
|---|---|
| 启动失败 | 看日志；TLS 开启但证书缺失会直接退出 |
| app 连接失败 | `DOCREADER_ADDR`、compose 网络、50051 健康检查 |
| 解析很慢 | 调低 `PDF_RENDER_PARALLELISM`/DPI；大 PDF 先确认是否扫描件 |
| 图片不显示 | app 侧存储配置；DocReader 只返回 inline bytes |
| 网页抓取失败 | 代理/SSRF 白名单；`DOCREADER_EXTERNAL_*_PROXY` |
| 表格缺失 | 检查解析器回退链与 Excel 结构；必要时补 registry/parser |
