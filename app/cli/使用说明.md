# CLI 使用说明

`wellread` 是 WellRead 的命令行客户端，用于认证、管理知识库/文档、混合检索、流式问答、Agent 会话和 MCP 暴露。面向人类交互和 AI Agent 自动化。

完整 Agent 契约、JSON envelope、退出码和确认协议以 [AGENTS.md](AGENTS.md) 为准；本文是人类使用入口。

## 1. 安装

要求 Go 1.26+：

```bash
cd app/cli
go build -o wellread .
sudo mv wellread /usr/local/bin/   # 或放入 PATH
```

当前不发布预编译二进制；如需固定版本，在仓库内构建并自行分发。

## 2. 认证与 profile

CLI 支持两种认证方式。

### 持久化 profile

```bash
wellread profile add prod --host https://kb.example.com --use
wellread auth login                  # 交互输入账号密码
wellread profile use prod
wellread auth list
wellread auth logout
```

profile 记录服务地址；凭据优先写入系统 keyring，其次写入 `$XDG_CONFIG_HOME/wellread/secrets/`（0600）。

### 无状态环境变量

适合 CI / Agent：

```bash
export WELLREAD_HOST="https://kb.example.com"
export WELLREAD_API_KEY="sk-..."     # 租户 API Key
# 或
export WELLREAD_TOKEN="<bearer-jwt>"

wellread kb list
```

使用 `--profile <name>` 可临时指定 profile。

## 3. 五分钟上手

```bash
wellread profile add prod --host http://localhost:8080 --use
wellread auth login

wellread kb list
wellread link --kb my-kb              # 绑定当前目录
wellread doc upload notes.md
wellread doc wait doc_abc             # 0=完成，1=失败，124=超时，130=取消
wellread search chunks "RRF 是什么"
wellread chat "总结这份设计文档"
```

Agent 会话：

```bash
wellread model list
wellread agent list
wellread session ask --agent ag_abc "Q4 留存计划是什么？"
```

分块与会话排查：

```bash
wellread chunk list --doc doc_xyz
wellread message list --session sess_abc
wellread message search "retry policy"
```

## 4. 命令矩阵

| 命令 | 作用 |
|---|---|
| `profile` | 命名连接目标（增删改查/切换） |
| `auth` | 登录、登出、查看凭据 |
| `kb` | 知识库 CRUD、状态/检查 |
| `doc` | 文档上传、重解析、等待、删除 |
| `chunk` | 分块查看/编辑（检索调试） |
| `search` | 跨 chunk/KB/文档/会话检索 |
| `chat` | 对 KB 的流式 RAG 问答 |
| `session` | 会话、消息、Agent 问答、工具审批 |
| `agent` | 自定义 Agent 管理 |
| `model` | 模型列表/创建/更新/删除 |
| `message` | 会话消息查看/搜索/删除 |
| `mcp` | 以 MCP server 方式暴露 CLI |
| `doctor` | base URL、认证、版本、凭据存储自检 |
| `api` | 原始 HTTP 透传 |
| `schema` | 输出命令机器可读契约 |
| `skills` | 列出/安装内置 Agent Skills |
| `version` | 构建信息 |

`wellread <command> --help` 是参数权威来源；`wellread schema` 供 Agent 读取。

## 5. 输出与脚本契约

- **stdout**：数据通道。`--format json` 输出 `{ok,data,meta?}`；`--format ndjson` 逐行输出列表。
- **stderr**：日志、进度、错误。stderr 非空不代表失败，必须看退出码。
- `--jq` 作用于整个 envelope，例如：

```bash
wellread kb list --format json --jq '.data[].id'
```

错误格式：

```text
<code.namespace>: <message>[: <cause>]
hint: <next action>
```

关键退出码：

| 码 | 含义 | Agent 动作 |
|---:|---|---|
| 0 | 成功 | 继续 |
| 1 | 本地/未知错误 | 看 stderr |
| 2 | 参数错误 | 重新查 help |
| 3 | 认证失败 | 重新认证 |
| 4 | 资源不存在 | 校验 ID |
| 7 | 服务/网络临时错误 | 退避重试 |
| 10 | 高风险操作需确认 | 先问人，再 `-y` |
| 124 | 超时 | 调大 timeout 或查任务 |
| 130 | 取消 | 停止，不重试 |

高风险命令（`kb delete`、`doc delete --all`、`session delete`、`profile remove`、`agent delete`）必须显式确认；脚本中先 `--dry-run`。

## 6. Agent / MCP

CLI 可作为 MCP server：

```json
{"mcpServers":{"wellread":{"command":"wellread","args":["mcp","serve"]}}}
```

内置 Agent Skills 可安装到 Claude/其他 Agent 目录：

```bash
wellread skills list --format json
wellread skills install
wellread skills install --dir <agent-skills-dir> --force
```

Agent 集成前先读 [AGENTS.md](AGENTS.md) 的 wire contract、exit-10 反模式和流式规则。

## 7. 常见问题

- 认证失败：确认 profile、`WELLREAD_HOST`、Key/JWT 是否指向同一服务。
- 命令找不到 KB：先 `wellread kb list`；目录绑定用 `wellread link --kb <id>`。
- 解析卡住：`wellread doc wait <id>`，或 `wellread doc reparse <id>` 后重试。
- 输出被脚本误读：使用 `--format json`，按 envelope 和退出码判断，不要解析人类文本。
- 权限不足：CLI 受租户 API Key/用户权限约束，不是绕过后端 RBAC 的工具。
