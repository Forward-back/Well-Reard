# 演示指南

> 状态：当前
> 最后更新：2026-10-26
> 目标读者：售前、产品、演示人员、新同事
> 关联：[系统总览](../01-项目总览/系统总览.md)、[角色生态位规定](../02-需求与设计/角色与权限/角色生态位规定.md)、[当前进度](../03-进度与交接/当前进度.md)

## 1. 演示目标

在 15–20 分钟内讲清三件事：

1. 文档进入系统后，能被解析、检索、引用，而不是“接个模型聊天”。
2. 权限、共享、协作、审计形成闭环，而不是靠页面隐藏。
3. 不同角色看到不同工作台，技术运维与公司治理分开。

演示不追求覆盖全部功能；按听众选择主线，避免在细节里迷路。

## 2. 演示前检查

- 六容器健康，`/health` 返回 200。
- 演示账号可登录；角色账号见[角色生态位规定](../02-需求与设计/角色与权限/角色生态位规定.md) §1.1。
- 演示 KB 已上传并解析完成；至少一篇文档有章节结构和引用。
- 精读模型、问答模型可用；技能目录有 1 个已启用技能。
- 共享出/共享入至少一组；协作区有 1 个 issue 和 1 个待审 CR。
- 治理台有可展示的聚合数据；不要展示空看板。
- 准备一个“无权限/无命中”的反例，用于说明边界。

## 3. 主线演示（20 分钟）

### 3.1 角色与入口（2 分钟）

- 用 manager 登录，指出侧栏：新对话、知识库、精读、共享空间、治理、管理。
- 说明这不是“超级管理员后台”：manager 管部门，company_admin 管公司治理，system_admin 管技术底座。

### 3.2 知识入库（3 分钟）

- 上传一份文档，展示解析状态：处理中 → 已完成；失败可重解析。
- 打开文档：文件夹、标签、文号/机构/日期/生命周期/密级。
- 说明正式内容修改走 CR，不直接覆盖。

### 3.3 问答与引用（4 分钟）

- 提一个需要跨段落的业务问题，展示流式回答。
- 打开引用：文档、章节、原文片段、文号/日期；跳转原文。
- 追问一次，展示会话上下文；打开改写卡片与检索 trace。
- 提一个资料里没有的问题，展示拒答/未找到，不编造。

### 3.4 权限与共享（3 分钟）

- 用 viewer 登录共享空间，打开共享入 KB：只读、可问答、不能编辑/删除。
- 说明 ACL deny 优先于角色；引用和检索都经过同一权限范围。
- 不要展示原始问题日志；治理只看聚合。

### 3.5 协作与版本（4 分钟）

- 在文档中提一个 issue，绑定到具体段落。
- 新建 CR，展示 diff、审阅者、审批状态。
- 说明：审计员可审批，manager 才能合并；合并生成版本，可对比/回滚。

### 3.6 精读（3 分钟）

- 从引用面板或精读页选 1–2 篇文档，选“标准”深度。
- 展示阅读计划、关键节点问题卡（带推荐解读）、阅读笔记。
- 说明精读只读、范围固定、每步复核权限，报告可导出。

### 3.7 治理/运维（1–2 分钟，按听众）

- company_admin：公司看板 + 审计，不进入 KB 正文。
- system_admin：`/ops` 七分区，模型/队列/账号救援，独立工作台。

## 4. 分角色演示路径

| 听众 | 账号 | 重点 |
|---|---|---|
| 部门负责人 | manager | KB 设置（共享/ACL）、成员/审计员、部门看板、CR 合并 |
| 知识库管理员 | knowledge_admin | 建库、技术配置、文件夹、技能、部门看板 |
| 编辑 | editor | 上传/编辑、issue/CR、无删除/管理入口 |
| 只读成员 | viewer | 阅读/检索/精读、共享空间、issue 评论、无 CR 提交 |
| 公司管理员 | company_admin | 公司治理/审计、成员/部门，业务路由 403 |
| 系统管理员 | system_admin | `/ops` 健康、模型、队列、账号运维、系统审计 |

## 5. 演示纪律

- 只用演示数据，不用真实客户文档、真实密钥、真实员工问题。
- 不承诺未落地能力：知识缺口 Top5、完整陪读 UI、MCP 技能暴露等按“规划中”说明。
- 不展示原始问题文本；治理只展示聚合。
- 失败就明确说失败：解析失败、模型不可用、无权限都是产品边界的一部分。
- 时间不够时砍功能，不砍权限与引用这两条主线。
