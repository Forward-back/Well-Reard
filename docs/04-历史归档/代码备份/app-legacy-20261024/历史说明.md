# app-legacy-20261024

本目录归档自 `app/` 的 WeKnora 上游遗留内容，不参与当前 Gaze / WellRead 的 Go、前端、Docker 或 CI 构建。

## 内容

- `miniprogram/`、`tests/miniprogram/`：旧微信小程序及测试。
- `docker-compose.dev.yml`：旧全栈编排（sandbox / odl-hybrid / searxng / dex 等）。
- `docker/Dockerfile.odl-hybrid`、`docker/Dockerfile.sandbox`、`docker/sandbox-pty-prompt.sh`、`docker/searxng/`：旧镜像与检索/沙箱配置。
- `dex-config.yaml`：旧 dex 身份代理配置（原 `misc/`）。
- `skills/`：旧技能样例（原 `examples/skills/`）。
- `ci/docker-image.yml`、`ci/dsh-plugin.yml`、`ci/release-lite.yml`：旧镜像发布、dsh 插件与 Lite 发布 CI（Lite 发布依赖已删除的 cmd/desktop）。
- `dev.sh`、`quick-dev.sh`、`start_all.sh`：旧全栈开发/启动脚本；当前使用 `docker compose` 与 `make dev-start`。

## 恢复方式

需要追溯时可直接查看；如需恢复某一项，移回 `app/` 对应路径并同步恢复 `.github` 引用。当前主栈使用 `app/docker-compose.yml` 与 `app/docker-compose.hotreload.yml`。
