## 6. 风险与已知边界

- Docker Desktop 拉取基础镜像不稳定、内存不足会导致 app/ylsw 重建失败；旧镜像与新源码混用可能掩盖部署问题。
- RAG 数据在仓库内 `data/rag/`（gitignore）；迁移仓库或更换机器时必须同步该目录，否则问答/精读不可用。
- 检索审计只存 query hash；治理看板不能展示原始问题，知识缺口能力受限。
- 部门审计员与单 CR reviewer 无角色下限；合并门槛已实施且提交人不能自审，但提交人/审批人/合并人完全三人分离未强制，manager 可以是审批人之一并合并。
- 版本回滚已验证稳定 chunk ID、内容恢复与 `content_revision` 递增；软删除 chunk 已可恢复原 ID；引用尚未绑定 `version_id`，并发合并/版本号竞争仍可能出现冲突。
- 部分历史文档（阶段记录、归档）保留旧路径与旧文件名，仅作历史快照；当前口径以 `01`/`02` 为准。
