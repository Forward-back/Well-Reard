## 1. 设计决策

- **技能选择不改权限**：所有登录成员均可选择启用中的技能；`skills:view` 只控制技能管理页，不控制问答选择。
- **启用状态**：`tenant_skill_catalog.enabled`，默认 true；禁用后不出现在选择器，也不能被问答注入。
- **注入载荷**：App 解析 `skill_id` 后读取 catalog，校验启用、非空 instructions、长度 ≤ 32000 字符，冻结 `id/name/version/content_hash/instructions` 后传给 YLSW。
- **注入位置**：YLSW 将 skill instructions 作为 `tag_content` 之后的低优先级 `<skill_instructions>` 片段；不得覆盖系统指令、检索 ACL 或引用规则。
- **版本留痕**：assistant 消息新增 `skill` JSONB：`id/name/version/content_hash/injection_status`；历史消息保留当时版本与哈希。
- **失败策略**：App 侧选择校验失败直接返回错误；YLSW 侧 skill 载荷非法时 fail-open 跳过注入（不影响普通问答）。
