## 1. 精读收口

- 固定内置 `grill-with-docs`，忽略部门技能；三档深度写入阅读计划。
- 创建后先确认阅读计划；三栏工作台、自动推进、停止/恢复、中途加文档。
- 知识库、精读文档、添加文档选择器支持关键词搜索；文档加载上限 500。
- 引用面板同 KB 多选（最多 5 篇）；会话 `reading_run_id` 与历史“精读”标识。
- 服务端导出 Markdown/JSON，导出前逐文档复核 ACL，报告含覆盖与局限。
- 运维台新增精读模型页；部门看板新增精读任务/完成数聚合。
- 受限动作集支持 `search_selected_docs`；修复笔记补丁对象数组解析、模型失败误标章节已读、历史 RAG 引用入口、`sessionActivity` 未初始化导致导航失败。

## 2. 协作、治理与检索

- 合并前要求至少一名其他审阅者/部门审计员批准；提交人不能自审。
- 软删除 chunk 回滚恢复原 ID，避免锚点失效。
- CR 审批写入治理审计 `collaboration.cr_reviewed`。
- 治理审计支持筛选、分页、CSV 导出；部门看板新增精读聚合。
- ACL 过滤抽成 `rag/src/retrieval/acl_filter.py`；Text2SQL 聚合等无文档 ID 候选在 allow/deny scope 下 fail-closed。
- SQLite 修正 000014/000019/000025 迁移，fresh 与 v4 升级测试到 version 32 通过。
- 内网部署端口收敛为 frontend `6151`、app `6152`；ylsw 改为 Docker `expose 5000`，不占宿主端口。

## 3. 登录页

- 左侧旧轮播卡片替换为 Archify 交互式架构图，暖色 editorial、中文标签。

- iframe 使用 embed 加载后移除 `data-embed`，注入登录页样式隐藏 Viewer 外壳，并恢复 motion。
