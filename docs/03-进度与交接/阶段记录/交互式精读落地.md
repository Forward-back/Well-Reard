## 1. 设计决策

- **独立链路**：ReadingRun 不走 YLSW 检索，只读取用户显式选中文档的全文 chunks；使用独立 `tenants.reading_model_id`。
- **v1 分节**：按 chunk ContextHeader 聚合章节；无标题按 chunk 顺序；超长章节按 8000 字符窗口切分。
- **动作集**：`plan / read_section / ask_user / update_notes / finish`。App 负责校验，LLM 每步只返回一个动作 JSON。
- **一次一问**：每步最多一个问题，必须附推荐答案；能读文档回答的不问用户。
- **权限**：创建 Run 时逐文档校验 KB 访问 + 文件 ACL/deny；任一不可读则拒绝整个 Run。LLM 不能增加文档，`add-documents` 必须用户显式调用并重新校验。
- **笔记增量**：每步合并 `notes_patch`，不攒到最后；矛盾必须带两处出处。
- **消息**：assistant 消息元数据记录 `reading_run_id`；阅读状态不塞进消息大字段。
