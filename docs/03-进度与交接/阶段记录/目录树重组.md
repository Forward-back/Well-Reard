## 4. 关键路径约定

- compose 项目名固定为 `app`，沿用原 postgres/redis 命名卷。
- app/docreader 上下文：`../app`；frontend：`../frontend`；ylsw：`../rag`。
- 前端能力契约：`frontend/src/config/capabilities.ts` → `app/contracts/capabilities.json`；镜像通过 named context `contracts` 注入到 `/app/contracts`。
- RAG：`RAG_DATA_DIR=/app/external/Data`，`LOCAL_MODELS_DIR=/app/external/models`；FAISS 索引写 `dirname(DATA_DIR)/faiss_index.bin`。
- 根 `scripts/` 只放跨服务脚本；Go 构建脚本在 `app/scripts/`；前端脚本在 `frontend/scripts/`。
